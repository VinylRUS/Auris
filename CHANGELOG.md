# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версионирование — [SemVer](https://semver.org/lang/ru/).

## [0.0.1c] — предрелизная сборка

Фокус релиза: «подключаем всё, что можно подключить» — ранее добавленные,
но не задействованные в интерфейсе методы API теперь работают в UI.

### Исправлено

- **Сайдбар больше не уходит под панель воспроизведения**: разделы
  «Настройки» и карточка профиля перекрывались плавающим плеером —
  сайдбар теперь заканчивается выше плеера, как в Яндекс.Музыке.

### Добавлено

- **Тексты песен**: панель лирики (кнопка в плеере), автозагрузка
  `GET /tracks/{id}/supplement`, кеш по треку, аккуратная типографика
  построчно, состояния «загрузка»/«текст не найден».
- **Альбомы**: плитки новинок открывают альбом (`GET /albums/{id}/with-tracks`)
  с обложками; лучший результат поиска типа «альбом» тоже открывается.
- **Исполнители**: открытие карточки исполнителя
  (`GET /artists/{id}/brief-info`) с популярными треками — из поиска
  и библиотеки.
- **Библиотека**: секции «Альбомы» и «Исполнители» из лайков
  (`GET /users/{uid}/likes/albums`, `.../likes/artists`).
- **Радио**: станции из дашборда ротатора (`GET /rotor/stations/dashboard`)
  с фолбэком на встроенные жанры/настроения.
- **Подсказки поиска**: живые саджесты при вводе
  (`GET /search/suggest`) с дебаунсом 350 мс и выпадающим списком.

### Изменено

- Версия: `0.0.1-beta.1` → `0.0.1-beta.2` (отображается как `0.0.1c`).

## [0.0.1b] — 2026-10-27

Первый релиз с установщиком и автообновлением. Device Flow проверен на живом API.

### Добавлено

- **Установщик Windows** (Inno Setup): установка per-user в `%LOCALAPPDATA%\Auris`
  без прав администратора, ярлыки, деинсталлятор, русский/английский мастер;
  при обновлении запущенное приложение закрывается автоматически.
- **Автообновление**: тихая проверка GitHub Releases при запуске и по кнопке
  в настройках; скачивание установщика с прогрессом и отменой, проверка
  SHA-256, запуск установщика и перезапуск (Windows); на Linux/macOS —
  переход на страницу релиза. Канал — `latest.json` в «последнем» релизе.
- **Иконка приложения** (Fluent-стиль, эквалайзер) + метаданные версии
  в `auris.exe` (FileVersion/ProductVersion через winresource).
- Карточка «Обновление» в настройках: статус, примечания к версии,
  прогресс-бар, отмена, повтор при ошибке.
- CI: релизный пайплайн собирает установщик на Windows-раннере, публикует
  `Auris-Setup-<версия>-x64.exe`, портативные архивы, `latest.json`
  и `SHA256SUMS.txt`.
- **Полный редизайн интерфейса**: 34 векторные SVG-иконки Fluent-стиля
  (тонировка `colorize`, чёткость на любом DPI) вместо текстовых unicode-глифов;
  кнопки окна в стиле Win11 (крест с красным наведением); анимированный
  эквалайзер у играющего трека; hover-состояния и плавные переходы у всех
  контролов; кнопка play на плитках при наведении; проявляющиеся действия
  в строках треков; громкость с mute по клику; тень у плавающего плеера;
  «дышащие» волны на главной и волне; демо-режим UI (`AURIS_UI_DEMO=1`)
  для скриншот-тестирования.

### Изменено

- Версия: `0.0.1-alpha.1` → `0.0.1-beta.1` (отображается как `0.0.1b`).
- Вёрстка страниц: фикс «разъехавшихся» пустот — всем Flickable задано
  `alignment: start` и честные `content-height`.

## [0.0.1a] — 2026-10-27

Самая ранняя альфа. Каркас приложения целиком, без обкатки на живом API.

### Добавлено

- **auris-api**: клиент API Яндекс.Музыки — OAuth Device Flow, статус аккаунта,
  лента, поиск, плейлисты, лайки, варианты загрузки с вычислением прямых ссылок
  (`md5(SALT + path + s)`), Rotor Session API («Моя волна», станции, фидбек);
  golden-тесты на зафиксированных ответах.
- **auris-player**: плеер-сервис на rodio + symphonia (play/pause/seek/volume),
  события окончания дорожки, снапшот состояния для UI.
- **auris-core**: конфиг (JSON), хранилище токена (keyring + файловый fallback),
  кеш обложек и аудио, менеджер загрузок с прогрессом, локальная история.
- **auris**: Slint UI — экран входа (QR + код + резервный токен), главная,
  поиск, библиотека, «Моя волна», радио, скачанное, настройки; плеер-бар,
  очередь, кастомный титлбар без нативных декораций.
- Темы: Fluent Dark/Light, тёплая пастель, мятная пастель, монохром Dark/Light
  + пользовательский акцентный цвет с автоконтрастом текста.
- Медиа-контролы ОС (SMTC/MPRIS) через playwire, фича `media-controls`.
- CI: проверка сборки на Ubuntu/Windows/macOS, тесты API-крейта.
